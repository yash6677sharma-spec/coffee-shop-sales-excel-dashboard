# Coffee Shop Sales — Excel Dashboard

## 📊 Project Overview

This project is an Excel-based Coffee Shop Sales Analytics dashboard built to analyze transaction-level sales data and turn it into business-focused insights.

The project uses a large coffee shop transaction dataset and Excel Pivot Tables, formulas, dashboard visualizations, and forecasting to explore sales performance.

## 🎯 Project Objectives

The analysis focuses on:

- Total revenue and sales performance
- Product category performance
- Product-level sales
- Store and location performance
- Transaction quantity
- Average selling price
- Sales by weekday
- Sales by time of day
- Pivot-table based business analysis
- Sales trends over time
- Revenue forecasting
- Forecast confidence intervals

## 🛠️ Tools Used

- Microsoft Excel
- Pivot Tables
- Excel Dashboard
- Excel formulas
- Data Analysis
- Time-series Forecasting
- Data Visualization

## 📁 Project Files

### 1. Raw data.xlsx

Contains the original transaction-level dataset.

**Sheet:** `Transactions`

The dataset contains approximately **149,000 transactions** with fields including:

- Transaction ID
- Transaction Date
- Transaction Time
- Transaction Quantity
- Store ID
- Store Location
- Product ID
- Unit Price
- Product Category
- Product Type

### 2. dashboard.xlsx

Contains the Excel dashboard and supporting Pivot Tables.

**Sheets:**

- `Dashboard`
- `Pivots`
- `Pivot table`
- `Transactions`

The Transactions sheet also includes calculated fields such as:

- Weekdays
- Day Bucket

These are used for time-based analysis in the dashboard.

### 3. forecasting.xlsx

Contains the sales forecasting analysis.

**Sheets:**

- `Sheet2`
- `Forecast`
- `Pivot table`
- `Transactions`

The forecasting workbook includes:

- Historical sales values
- Forecast values
- Lower confidence bounds
- Upper confidence bounds
- Forecast statistics

## 📈 Analysis Performed

### Product Analysis

Revenue, quantity, and average price are analyzed across product categories and products.

### Store & Location Analysis

Transactions and revenue can be compared across different coffee shop store locations.

### Time Analysis

Sales are analyzed using:

- Date
- Weekday
- Morning
- Afternoon
- Evening

### Pivot Table Analysis

Pivot Tables are used to aggregate transaction data and answer business questions efficiently.

### Dashboard

The dashboard brings the main sales metrics and analysis together into a visual reporting interface.

### Forecasting

The project also includes time-series forecasting to estimate future sales and display forecast confidence ranges.
